# Ceiling source receipt replay

## Observed production path

The original ceiling customer issuer composes `SourceVisibilityProducer` text
receipts, `CrossViewRoomAreaProducer` area evidence, authenticated RCP ceiling
correspondence, the existing ceiling quantity, source seal and customer row.
Native text receipt IDs hash the complete native proof decision. The optional
embedded-symbol proof can change an original glyph-unverified decision into a
trusted decision without changing the source word, revision, snapshot or its
physical dimensions. That changes downstream evidence IDs and sealed bodies.

The protected historical ceiling rows were issued before that native proof
was available in the runtime. Their glyph-unverified words required the
existing independent two-render raster corroboration. Installing the font
dependency changes the native proof stage; it does not change either measured
ceiling area. A source-only comparison recovered the same 21 selected native
observations under both environments with different proof decisions.

## Bounded correction

`source_raster_text_receipt_replay` is an explicit boolean, default off, on the
existing visibility producer. It requires the existing native source opt-in.
The current full native classifier always runs first. Any native contradiction,
occlusion, clip, opacity, optional-content or other failure is returned directly.
Only after native success does replay derive the original pre-symbol native
receipt using the same raw-source visibility checks.

The classifier itself builds that receipt decision; no receipt ID, status or
fingerprint is rewritten. A glyph-unverified receipt stays untrusted. Existing
raster, dimension, room ownership, RCP correspondence, issuer, sealing and
customer gates must all pass. The proof policy participates in the visibility
page cache key. Ordinary/default callers and floor-finish issuers keep their
current native proof path.

The existing ceiling issuer explicitly selects this policy. Source-derived
reconstruction reproduced both archived area-evidence IDs exactly before this
wiring was added. The final source replay must also reproduce the complete
protected historical sealed and customer bodies. Archive
values and benchmark references are verification inputs only; they never enter
the producer or quantity calculation. No snapshot aliases or archive-based
prediction are introduced.

## Verification and boundaries

Source-neutral regressions cover full receipt equality across native proof
availability, default behavior, current native failure vetoes, strict opt-in,
untrusted published receipts, deterministic replay and invisible original text.
Protected validation must compare both ceiling rows and all dependent customer
bodies against their unchanged archives. Existing signed floor and finish
records, all other projects, original PDFs, frozen120 and evaluator rules remain
unchanged. A successful ceiling retention check is not a new benchmark score.
