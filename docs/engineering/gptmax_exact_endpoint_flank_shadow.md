# Original-source local W2 endpoint experiment

## Architecture report

Read: `AGENTS.md`, `docs/AI_ENGINEERING_PLAYBOOK.md`,
`docs/wall_topology_observability_architecture.md`,
`docs/planreader_wall_room_topology_spec.md`,
`docs/planreader_public_tender_benchmarks.md`, and `.github/workflows/ci.yml`.

Observed repository behavior: `original_raster_host_ancestry_census` executes
the established opening/host authority on immutable source bytes.
`original_full_foreground_report` separately authenticates complete positive
raster runs; the ordinary visibility reader refuses this shadow source kind.
`full_foreground_flank_census` retains every source-positive alternative at
the existing required-flank projection predicates.

`_trace_sources` calls `build_wall_graph_for_viewport`: structural metadata
filter, existing intersection splitter, endpoint snap, then degree-two
collinear merge. The W2 graph retains collapsed fragment receipts.
`deduplicate_coincident_edges` and `classify_junctions` produce W3;
`assemble_wall_candidates` produces W4 candidates. `_flank_stage_rows` reports
local geometric survival separately from source ancestry and physical host
authority. A remote surviving fragment never substitutes for a local loss.

Inference: endpoint snapping can destroy a real short source fragment before
W3/W4. Its original receipt may persist even though no qualifying local
geometry survives. A controlled synthetic one-point fragment reproduces this
failure. That alone does not establish that any particular drawing fragment
is structural wall evidence.

Proposed experiment: reuse that same W2/W3/W4 stack with its unchanged default
and with `gap_snap_tolerance_pt=0.0`, on **identical source inputs** for each
opening. This is a diagnostic configuration, never a production tolerance
change. No second splitter, snapper, scale resolver or canonical graph is
introduced. The existing zero-tolerance snap implementation is used as-is.

Each local input set contains every full authenticated primitive whose bounds
intersect the complete bounds of the original matched flank runs. No cropping,
radius search, nearest owner, first owner, or source-parent transfer occurs.
The local default control separates crop/scope effects from snap-mode effects;
neither local control claims to reproduce full-page topology. Bounds can keep
unrelated linework and are not authenticated floor-plan viewports.

Expected abstentions: every local W4 candidate still requires authenticated
structural role, viewport ownership and physical equivalence. Ink, lineage,
local continuity and a collision-free candidate address cannot publish a host,
opening count, measurement or quantity. An absent flank source raises; it is
not replaced with an empty complete universe.

Benchmark observations excluded from implementation: Lot16 source counts,
physical opening IDs, source SHA and drawing names appear only as original
source test controls. None select geometry or tune algorithms. Frozen V2
truth, denominator, tolerances, evaluator and scoring stay untouched.

## Authority review

Only one existing diagnostic function gains an explicit boolean opt-in.
Its default call path and output remain unchanged. New extraction logic lives
in a nonpublishing script. All production `pb_*` files, live commercial
writers, W10 eligibility, the original 20,000-input-primitive limit and the
frozen benchmark files remain untouched.

The public reader accepts original immutable PDF bytes and canonical source
scope, not caller-authored source JSON. It freshly authenticates both ordinary
and shadow pixel observations. After the two local graph experiments it
independently repeats the original production census and requires exact
whole-report equality, retaining original opening binding and host-frame
receipts. Derived fragments are not counted as input source primitives.

## Original-source experiment and revised inference

Local replay of the original PDF SHA
`10109b4b6e85e6e27af81f6399ce4b92abfdba80f87dc69dd5887bd6f3a65844`,
page 3, preserves exact complete production reports before/after: 21 positive
opening hypotheses, 14 authenticated hosts and nine frames. The complete
ordinary plus positive-pixel inventory has 10,099 input primitives. Seven local
input sets have 59, 66, 34, 39, 37, 125 and 37 source primitives respectively;
these are input counts, not physical wall or opening quantities.

The unchanged single-fragment flank predicate still abstains on three required
flanks even with endpoint tolerance zero. Inspection of the actual output
shows why: real raster lattice intersections split each source run into short
fragments, typically half-point spans. All original intervals survive with
their own source parents and retained W3 addresses, but no individual fragment
satisfies the existing combined endpoint/local-overlap predicate. Thus "no qualifying
single fragment" does not establish that all source geometry was lost.

The new read-only interval inventory distinguishes complete W2 coverage and
complete W3-retained coverage from that existing single-fragment result.
It joins only mathematically adjacent/overlapping intervals on the exact same
original axis, retains every address, and exposes every uncovered interval.
It does not smooth, pad, bridge gaps, rewrite graph edges or borrow ancestry.
Original predicate results remain visible and unchanged.
