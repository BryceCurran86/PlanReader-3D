# Public full-regression jobs and indexed receipt integrity

Observed: the opening/wall-face workflow's duplicate full-regression matrix
compiled/imported code into indexed receipt packages and treated absent private
sources as ordinary source failures. Its required CI counterpart and two sibling
workflows already use an external bytecode cache and explicit public source-
unavailable policy. Discovery found six duplicate matrices in total, four missing
the shared policy. The old allowlist covered only the two repaired copies.

Inference: generated bytecode is not a source receipt and must not change the
archived inventory. A public checkout without originals cannot prove source
acceptance. Neither issue justifies modifying receipt indexes or weakening source
assertions.

Change: apply the identical existing flags only to the public full-regression
job; put runner-dependent cache paths at step scope. Keep the full test, syntax,
truth-isolation and smoke commands. Separate original-source jobs receive no
omission policy. Discover every named full-regression matrix so future copies
cannot evade the shared contract. Execute actual compileall against a synthetic
indexed tree and prove byte-for-byte tree preservation and external bytecode
creation.

Benchmark non-inputs: no expected measurement, quantity, score, tolerance or
identity map is used. This infrastructure change modifies no producer, original
PDF, signed/customer fixture, frozen evaluator or geometry safety limit. Public
omissions remain NOT VERIFIED; no original-positive or quantity gain is claimed.
