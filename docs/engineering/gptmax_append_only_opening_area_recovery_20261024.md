# Append-only original-source opening-area recovery

Owner-authorized GPT MAX implementation; independent reviewer sign-off is
optional under current AGENTS.md. This is not a change to frozen truth.

## Observed problem

Replaying an enriched opening-primitive policy can produce an additional
source-owned physical opening and figured area. Replacing the entire original
claim also reissues previously signed source/host evidence. Equal amounts and
quantity IDs do not preserve the old signed bodies or customer provenance.

## Production path

`collect_live_physical_net_wall_claim(...,
recover_additional_opening_areas=True)` first executes the unchanged collector.
On one explicitly selected topology page, a separate original-source producer
replays the existing paired-face, unmeasured-flank and source-fragment-role
policies. Existing physical-opening and host authorities reauthenticate each
published candidate, and source-owned physical distinctness is checked against
the baseline competitors. Each object retains its actual snapshot and lineage.

Composition rejects a lost or changed previously published measurement, altered
physical/source support, foreign source root, duplicate quantity, or duplicate
physical claim. It retains the original measured canonical objects and original
QuantityEvidence instances. Only additional eligible areas and their actual
canonical objects are appended; source count, metric axes, rooms and walls are
not inferred or promoted by this operation.

The existing area issuer, source trace builder, V1 sealer and customer projector
then validate the final claim. No archive is read by production recovery. No
scale resolver, evidence schema, canonical graph, or signer is added. Default
and explicit-false behavior remain unchanged.

## Reproduction and acceptance

The existing original-source handoff command accepts
`--recover-additional-opening-areas`. Its output is still unscored until source
identity bindings and the unchanged frozen evaluator are applied separately.

Run `tests/test_live_append_only_opening_area_composition.py` for production
composition/seal/customer positives, source conflicts, malformed scopes and
default retention. Set `PLANREADER_LOT16_ORIGINAL_PDF` to the owner-authorized
original and run `tests/test_live_append_only_opening_area_original.py` for real
producer-to-signed/customer acceptance. A missing private original is reported
as unverified, not a passing source replay. Existing signed quantity/customer
bodies must remain exactly equal; any addition requires its own source proof.

The 20,000 primitive cap, 2.5pt snap, original PDF bytes and frozen benchmark
files remain unchanged. No default height, count, label proximity, expected BOQ
value or benchmark item ID enters the recovery algorithm.
