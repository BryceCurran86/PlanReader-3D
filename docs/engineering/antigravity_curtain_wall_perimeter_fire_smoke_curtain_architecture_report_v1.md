# Antigravity Architecture Report: Curtain Wall Perimeter Slab-Edge Firestop & Smoke Seal Shadow Authority (v1)

## Executive Summary
This report defines the deterministic shadow extraction authority for curtain wall perimeter slab-edge firestop systems, mineral wool safing insulation, elastomeric smoke seals, and safing support brackets from architectural facade detail and fire engineering drawings.

## Scope & Target Geometry
- Identifies perimeter slab-edge firestop joints between suspended concrete slab edges and exterior curtain wall spandrel panels.
- Classifies joint gap width (e.g. 50mm, 75mm, 100mm, 150mm), fire resistance rating (FRL / F-Rating), safing mineral wool density and compression, smoke seal coating type, and safing clip bracket support spacing.
