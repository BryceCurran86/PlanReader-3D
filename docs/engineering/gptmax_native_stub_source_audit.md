# Native interior-stub source audit — architecture review

Observed on refreshed main 067e01d3: `_visible_all_structural_candidates`
combines strong six-support nominations with generic correlated nominations,
excluding generic support sets contained by a strong support set. PR #2511
removes strong face breaks before this combination. Its archived original
source comparison changes 125 -> 189 native candidates (74 added, ten removed).
The strong discovery function on current main is AST-identical to the PR's
recorded baseline. The final nomination tuple is not opening or wall authority.

Functions traced: `SourceVisibilityProducer.ingest_native_pdf_bytes` ->
`augment_with_raster_visible_segments` -> `resolve_visible` (through the existing
`_default_source` reader), then `PhysicalOpeningAuthority._visible_structural_candidates`
and `_visible_all_structural_candidates`. Source scope, line geometry,
`_face_break`, `_collinear`, `_projection` and the existing coordinate allowance
define the proposed geometric witness. `_source_page_segments` independently
recovers owned literal paint descriptors from the same original PDF.

Inference: an exact per-ID source ledger can identify which added generic
nominations were previously shadowed by removed strong supports, and which
literal source segments lie strictly inside their proposed gaps. Raw visible
ink does not by itself establish structural wall role, physical nonexistence,
host ownership or a complete opening universe.

Proposed: a read-only source audit, comparing the existing main function with
the exact proposed PR function only if its baseline AST matches current main.
Retain every changed candidate and every interior-source alternative. Produce
original source observations, line/gap intervals, literal graphic descriptors,
and exact old/new support-set relationships. Do not alter candidate discovery,
accept a source-parity failure, filter W2, or promote any quantity.

Expected abstentions: every physical wall-role, host, equivalence, count and
metric proposition remains unproved. Missing source membership, changed
baseline semantics or unauthenticated source bytes must reject the audit.
Validation is the original PDF replay plus syntax/source identity checks;
existing source-parity and CI gates remain unchanged. The frozen V2 benchmark,
20,000 input cap, production authority modules and commercial writers remain
untouched.

## Original-source finding

The explicit native-only experiment authenticates 1,727 native visible source
records within the ordinary 4,083-record native/raster visibility snapshot.
It is a low-level nomination audit, not a replay of the production candidate
closure or the archived 125 -> 189 closure ledger.

The proposed function reduces this nomination frontier from 664 to 181,
removing 483 six-support nominations. All 483 have original interior-source
geometry witnesses. There are 294 unique witnesses: 228 are boundaries of
unstroked, exactly white filled paths, and 66 are stroked black native paths.
Of the removed nominations, 464 have ONLY unstroked white-fill witnesses.
That source boundary geometry alone cannot prove solid structural wall
continuation; even the stroked paths still require wall-role proof. This
supports keeping #2511 blocked, not changing its parity assertion.

The exact witness and candidate identities are retained in the accompanying
checkpoint. No original hypothesis is deleted from production, no native/raster
candidate universe is declared complete, and no host or metric is promoted.
The source SHA and literal paint ownership are independently authenticated;
the source snapshot and source records remain unchanged. Syntax/lint validation
and this real source audit are the focused checks for this read-only addition.
