## Inference

Replaying both decoding scopes from the same immutable source can supply real
snapshot/scope records for GPT3. Matching a replay to an archived seal must use
the complete existing sealed payload and fingerprints, after the producer
finishes. It must not select producer inputs by a desired match or certify
cross-snapshot physical identity from a comparison alone.

The 81a45/f819 shared narrow pier remains independently blocked at structural
role and complete physical equivalence. Its source ink and isolated topology
do not authorize a production host correction. That work is retained while
this independent source-lineage task proceeds.

## Proposed change

Add a source-only diagnostic that reuses both existing replay and parity tools,
emits each actual decoded-page root, every original existence/host/frame source
record and complete W4 competitor evidence, and binds each sealed quantity to
its own real host/frame snapshot and decision scope. Reuse existing V1 sealing;
do not invent an attestation, rewrite an old seal or issue a migration token.
Retain all nonquantity and unhosted cases as well as signed cases. A missing,
foreign, duplicate or inconsistent source record fails closed. Snapshots stay
distinct even where all measured evidence matches.

Synthetic proof covers two original decoded roots, repeatability, source
mutation, forged/foreign/missing host and frame lineage, ambiguity/changed
competitors, lost original physical identities and no authority grants.
Original replay verifies exact source SHA, original 21/15/9/8 retention and
complete archived/owner V1 seal equality separately, without using benchmark
truth as a prediction input.

## Authority boundaries and exclusions

This reads original source → existing physical authorities → existing sealed
quantities. Its output is unsigned review evidence, never a signed scope token,
customer approval or a cross-snapshot identity grant. No topology, wall role,
host/frame, scale, quantity, publisher or signer module changes. Original PDFs,
frozen V2, evaluator, signed fixtures, W10 defaults, 20k cap, 2.5pt snap and 4pt
structural rule remain untouched. No benchmark score or new FIRM quantity is
claimed. Exact-head CI and separate source/consumer review precede any release.
