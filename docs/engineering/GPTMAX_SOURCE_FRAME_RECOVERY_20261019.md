# Source-owned opening frame recovery

## Observed repository behavior

The traced path is `SourceVisibilityProducer` source capture →
`compose_live_wall_opening_authority` → W2/W3/W4 ordinary and isolated
supplemental candidates → `OpeningHostBindingProducer` →
`OpeningHostFrameProducer._raster_binding_nodes` / `_scope_bindings` /
`_shared_host_frame` → canonical opening composition → the existing area
publisher. Figured-label area and complete rough-opening geometry have
separate authority gates.

The mixed-scope host resolver has an explicit `source_fragment_roles_shadow`
policy. It retains role-eligible segments of bent W4 candidates and re-proves
source primitive ownership, end closure and physical equivalence. Frame
reproof calls the same resolver without that policy. The source opening
aperture bbox is also not a certificate of constant wall thickness across
an entire connected component. Current whole-wall frame publication rejects
nonidentical raster band geometry rather than asserting an unproven profile.

The immutable original-plan replay on base `9d710108` produced 22 physical
opening candidates and 19 corroborated hosts in a fresh isolated capture.
Source identities and signed receipts differ from the default capture.
That counterfactual is not a replacement for original signed output.

## Inference

A policy mismatch can prevent independently authenticated supplemental
source members from entering the frame graph. Fixing that mismatch is
necessary but does not prove constant thickness, complete extent or a
physical wall's equivalence to every other aligned candidate.

## Proposed change and review boundaries

Propagate the explicit fragment-role policy to frame reproof in the isolated
composition. Require exact authenticated scopes and unchanged member identities;
retain all negative and conflicting results. Exercise actual raster-source
fixtures, adversarial scope/identity controls, deterministic replay and
metamorphic controls. Re-run original source and retain the original issuer.

Before any further geometry change, inspect the component's exact source band
faces and W4 source owners. Never replace the band consistency check with a
larger tolerance or use an unbridged distance as distinctness proof. Composite
profiles need an explicit geometry contract and compatible consumers before
whole-wall authority can be granted.

Default source capture, the 20,000 primitive cap, 2.5 pt global snap, W10
flags, original signed quantities, source PDFs, frozen truth, identity maps
and scoring rules remain untouched. Commercial additions require their own
source-closed authority review.

## Source-face refinement after trace

The fresh exact-source trace independently re-issued every physical support
observation for the connected opening component. All solid flank faces have
identical offsets; the aperture bboxes have different thicknesses. Therefore
reuse the host resolver's unchanged four-face/two-end closure predicate and
re-authenticate each support receipt in the frame producer. In the explicit
fragment-role shadow only, exact common solid faces define wall thickness and
frame normal origin. A nonuniform source band still abstains. No tolerance is
increased and no piecewise thickness profile is flattened.

After this correction, the component passes band consistency but still fails
whole-wall completeness against retained aligned W4 candidates. The isolated
shadow records every unproved wall/member pair in stable sorted order for
source review. Missing SAME/DISTINCT proof is not replaced by a distance test,
a perpendicular T-wall, a motif guess or absence of a detected opening.
