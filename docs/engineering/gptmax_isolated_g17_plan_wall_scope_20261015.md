## Observed repository behavior

Read `AGENTS.md`, the engineering playbook, topology specification and
observability architecture, G17 producer architecture, retired public tender
notice and CI workflow. Traced source ingestion and isolated G17 augmentation,
`build_opening_local_g17_wall_shadow`, source-owned F.07 generation and migration,

The opening-local shadow graphs three source primitives per flank. This is not

whose original neighbouring ink was never included. The original 144/300 source

## Inference

The next useful experiment is the complete producer-published G17 primitive
inventory in its own source-authenticated drawing viewport, rather than another
join between incompatible detector namespaces. Source band faces, ends and
neutral ink runs are candidate geometry, not structural wall semantics. Their
presence, W3 closure or unique W4 ownership cannot alone authorize a host.

## Proposed change and authority review

Add an isolated shadow builder addressed only by actual source producer,
revision and page. Reauthenticate the entire original G17 inventory and original
PDF before and after the operation; derive F.07 in the same immutable root and
validate it through the existing migration adapter. Retain inside, crossing and
outside primitives, original source paint negatives and every competing opening
claim. Run existing W2/W3/W4 on source-positive drawing geometry, keeping default
snap and exact-coordinate results separately. Never promote a narrow scope to a
complete wall or opening universe. Never alias 300-DPI primitive IDs into the
ordinary 144-DPI namespace or mutate published source state.

Expected abstentions include missing/ambiguous F.07, stale/foreign lineage,
unproved original paint, boundary crossings, collapsed jambs, W3 review nodes,
multiple W4 owners and unresolved physical wall semantics. Synthetic authentic
source, competitor, transform, replay and tampering tests precede original
replay. Original wall, opening, host, frame and area receipts must remain equal.

Review conclusion before implementation: this is a candidate-only experiment
within the authorized GPT MAX source lane. Existing wall/host authorities will
not accept this wrapper. A separate reviewed producer integration is required
if and only if original structural ownership and competing claims close.
