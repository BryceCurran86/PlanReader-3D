## Inference and proposed narrow fix
A single whole-room original physical floor face cannot be claimed by two simultaneously signed independent floor-area quantities. A pair of source-authenticated, separately simple polygons in the same source document SHA/revision/page/viewport and *exact* bbox that are topologically identical represents one physical source face, even when one ring begins at another vertex, reverses winding, includes explicit closure, or inserts a collinear intermediate source point. Reject the **entire** final floor trace/seal rather than selecting one ID. Distinct adjacent/nonidentical polygons and distinct page/viewport keep independent identities. This is a negative-only final source-ownership check using existing source rings; no source inference, metric area calculation, finish grant, tolerance or snap. An invalid or exception-throwing geometry remains fail-closed. Source SHA case-fold only after existing typed 64-hex validation.
