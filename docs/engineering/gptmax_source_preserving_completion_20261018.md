# Source-preserving opening recovery integration

## Observed behavior

Read AGENTS.md, the engineering playbook, adopted topology architecture,
wall/room specification, source/evaluator boundary, CI and shared working
agreement. Traced compose_live_wall_opening_authority through host binding,
OpeningHostFrameProducer._scope_bindings / _shared_host_frame, canonical void
composition, and publish_live_opening_area_quantities / _opening_quantity.

Ordinary complete W4 and incomplete supplemental scopes are separate. The
existing figured-label area seam requires its physical opening, source kind,
host and measurement receipt; it does not require complete 3D placement.
Geometry-derived area still requires complete metric geometry. Counts need a
separate complete opening universe.

## Inference and proposed change

Integrate previously published default-off recovery changes onto current main
without replacing newer main code. Reuse the existing full CI rather than
adding redundant automatic workflows. Separate potential additive area review
from the unrelated full-geometry gate. The existing publisher nominates the
measurements; this review layer neither creates nor changes measurement values.

Exclude all original quantity IDs, including alternate-snapshot reissues.
Retain physical-identity continuations and incomplete source DAGs as blockers.
Reject contradictory closure flags, duplicate parent observations and foreign
source parents. CLI revision-ancestry replay does not repair missing parents.

## Authority boundaries

Both source issuers remain independent. Existing signed quantities and customer
rows are retained separately. Every proposed addition remains candidate; append,
commercial projection, count and benchmark grants remain false. No signatures
or combined customer output are produced by this handoff.

Production publishers, source PDFs, benchmark truth/evaluator/mappings, raster
primitive limit, minimum raster run, snapping policy, scale and height defaults
remain unchanged. Private source replay outputs are not included in this PR.

## Validation

The source-focused integration suite, separate privately provisioned original
source tests, and additive-area review regression suite were executed locally.
Real original source production reproduced the original signed and customer
bodies. Full-suite and exact-head hosted CI outcomes are reported separately.

## Benchmark observations

Scores, source fixture coordinates, expected quantities and benchmark identities
were not used to select an opening, source threshold, dimension or host. Any
later evaluator runs only after production is frozen. This handoff does not
claim a new approved quantity or score gain.
