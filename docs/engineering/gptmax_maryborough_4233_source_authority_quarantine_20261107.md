# Quarantine of unsupported Maryborough customer quantities

GPT MAX, 7 November 2026. Corrective scope for merged #4233.

## Observed behavior

`issue_all_original_maryborough_customer_quantities` authenticates the PDF
digest, then constructs quantities from literal dimension products and counts.
Its word search names evidence but does not supply or validate the measurement;
an empty search creates a fallback evidence identifier. The producer also
constructs benchmark identity bindings and copies floor values into ceilings.

Protected original run 42352286231 retained the genuine PDF SHA and bytes.
Both the normal call and a call with unavailable native words returned 24 FIRM
rows. The compatibility wrapper returned two rows with the 24-quantity seal;
the existing customer verifier rejected that mismatch. No source-backed
accuracy increase follows from those outputs.

Repository caller search found only the new compatibility wrapper and tests
using this issuer. The existing live collector, source-owned floor/finish/RCP
issuers and original historical handoffs do not call it.

## Correction and authority boundaries

Withdraw this unsupported issuance path. Preserve its import names, result
type, source digest authentication and legacy identity aliases, but return an
explicit, empty ABSTAIN when no existing source-owned physical quantity
authority has been connected. Remove the literal measurement generator,
fabricated receipts, customer grants and producer-owned benchmark mappings.
The retained identity constants are compatibility aliases, not permission to
issue any physical quantity.

The subset wrapper must also refuse an unexpected upstream result instead of
borrowing a larger seal or forwarding residual rows. A future implementation
must use genuine typed quantities and corresponding traces, seal exactly the
returned physical set, and independently verify those exact customer rows.
Document identity alone never establishes that physical set.

This is containment of invalid output, not a new measurement implementation.
Existing source/physical/material/metric authorities remain the only route to
a future accepted takeoff. Unknown finished faces, thresholds, finishes,
ceiling boundaries, hosts, frames or complete counts continue to abstain.

## Validation

Replace the two shortcut-specific mirror tests with source-neutral negative
regressions: known fixture identity without quantity authority; unavailable or
empty native observation backends; wrong source and invalid workspace; and an
upstream FIRM or residual result that must not leak a borrowed subset seal.
Run corresponding checks against the genuine private original with its SHA
unchanged, plus the existing signed/customer retention checks on the fixed
commit and complete Python 3.13/3.14 CI.

The source-render cleanup, existing issuers, historical signed outputs, private
PDFs, frozen truth/evaluator, denominator, tolerances, primitive cap and snap
limit are unchanged. No benchmark value or item identity selects a prediction.
No score gain or resource improvement is claimed by this quarantine.
