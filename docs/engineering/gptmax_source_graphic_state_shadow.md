# Source graphic-state shadow prerequisite

Architecture report before implementation: original byte-authenticated source
observations -> existing `_source_page_segments` reconstruction/authentication
-> existing `lineage_from_source_segments` graphic-state descriptors. The
experimental W2/W3/W4 graph remains the existing `_trace_sources` result.

Observed: the foreground diagnostic preserves observation IDs/geometry but
its W2 inputs omit PDF stroke/fill/width/layer/dash/clip values. Their graph
sentinels are unknown, not actual source graphic state. The established wall
source producer can reconstruct those values from byte-owned native paths and
exact visible observation receipts. Pixel-run shadows do not own vector paint
commands, so absent graphic state must remain unavailable.

Inference: literal metadata cannot prove a structural wall, but recovering
its source ownership is a necessary prerequisite to a later role audit.
Feeding recovered attributes into Stage A would activate existing filtering
and change geometry; that is outside this descriptive task.

Proposed change: a separate read-only sidecar joins actual graph parents to
every byte/observation-owned ordinary source segment, validating exact source
geometry and retaining all alternatives. Reuse existing primitive-lineage
unknown/agreed/conflict semantics. Report missing pixel graphic state without
guessing stroke widths, layers or structural meaning. Keep the graph and
source records untouched; no copied physical identity or substitute graph.

Required proof: fresh PDFs, deterministic replay, geometry/parent tampering,
unrelated content, translation/rotation/scale, unknown pixel metadata, no
mutation, original full-page receipts and no publication. Synthetic values,
source/project IDs and observed counts must not select or tune geometry.
Frozen V2, cap, tolerances, W10, host/frame/measurement/count publication and
all production source/geometry modules stay unchanged.

The first original-source replay identified ten retained, tiny derived
fragments with empty source-parent inventories. Keep them as explicit
ABSTAINED graphic-state rows with unavailable ownership and all attributes
unknown; an empty parent set must not vacuously claim complete metadata.
Foreign/contradictory parents still raise. Do not borrow a nearby source line
or alter splitter/containment tolerances to explain these fragments.
