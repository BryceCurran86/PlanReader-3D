# Architecture: gusset plates must not invent 250 x 250 x 12 mm plates

## Observed repository behavior

`GussetPlateSpec` defaults to 250 mm width, 250 mm height, and 12 mm thickness.

## Inference

A typical gusset plate size is not owned evidence.

## Proposed change

Omitted gusset width, height, and thickness stay `0.0`. Gusset mass is 0 when dimensions are omitted.

## Benchmark observations that must not influence implementation

Expected steel tonnes and project names are not inputs.
