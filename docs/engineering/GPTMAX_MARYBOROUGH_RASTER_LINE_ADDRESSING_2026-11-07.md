## Observed cost

The bounded original floor producer repeatedly samples
`_authenticated_raster_source_lines` inside host binding. That helper resolves
every supplied source observation, then discards native segments and lines
from other pages. A source-native Maryborough plan therefore repeats native
alias validation without contributing a raster line.

The SHA-original two-page source provides 81,854 visible observations. With
the immutable parent helper, page-7 and page-11 raster-line reads take
4.118096s and 2.592522s respectively. Their full result dictionaries are empty.
The filtered helper returns exactly those dictionaries in 0.000011s and
0.000009s. Source ingestion took 13.707s. These are reader observations, not
an end-to-end floor, finish or customer result.

## Change and proof boundary

Add a pure `SourceVisibilityAuthority` raster receipt-page addressing method.
`resolve_visible` always takes its native branch when a native receipt exists;
that branch cannot return a raster visible segment. A missing raster receipt
or a raster receipt from another page also cannot supply this reader's line.
Keep only IDs that can reach its existing raster branch, retaining input
order and duplicate handling. Every retained ID still undergoes the complete
existing source, revision, snapshot, parent, render and geometry proof.

No positive authorization is cached. No host election, physical equivalence,
source completeness roster, frame geometry, tolerance or quantity is changed.
The empty-address case returns the same empty line dictionary without native
proof work. This filter grants no new physical authority.
