## Generic change

`tools/gptmax_full_foreground_run_source.py` is an isolated, separately
versioned source-observation producer. It consumes actual immutable
SHA-pinned native PDF bytes through SourceObservationProducer's owner seam,
re-renders the selected page at the existing 144 DPI, applies the **existing**
foreground polarity and fixed minimum genuine-segment length, and enumerates
every complete contiguous positive row and column. All original holes,
endpoints and page boundaries are preserved. Neither the PDF's name, project
identity, opening coordinates, missing-host count, material, expected quantity,
benchmark truth nor a target viewport controls nomination.

Each source-only observation is parented to the real native PDF page,
source SHA, snapshot, native frame, PNG hash, original scanline and pixel
endpoints. The independently sealed producer-specific authority authenticates
the observation against immutable render replay. A separate new observation
kind and primitive-ref namespace prevent collisions with ordinary raster or
the merged rejected-component producer. The ordinary visibility reader rejects
these experimental shadow observations. The 20,000 safety bound is tested
against native PDF segment sources plus *all* nominated runs before the
single atomic derived-observation append. Any over-limit inventory aborts:
no sampling, truncation or change to the bound.

`tools/diag_gptmax_full_foreground_run_source.py` independently
reauthenticates the ordinary original visible source inventory, source hashes,
unchanged normal snapshot and shadow authority. Optional `--trace-w2-w4`
replays the original experimental graph on complete source input, but grants
**zero** physical host, physical-equivalence, opening count or quantity
publication and does not claim a complete floor-plan view universe.
