physical ownership. Positive-only nomination cannot prove candidate coverage,
and an empty detector cannot prove universal nonexistence.

than merging #1754 or the historical #1953 stack. Authenticate all isolated
raster receipts and immutable source bytes before consuming cached geometry.
Retain every weak band-gap hypothesis; resolve one only through exact aperture
and complete source support of independently re-proven physical existence.

candidate family, not universal completeness. Existing native source, view,
physical identity and universe gates remain necessary.

namespace. Page IDs address source scope only; output has no measurements or

source sets. It uses the same production source and physical-opening producers
without constructing wall/room topology, and reports unavailable raster audit
capability explicitly when run against an older authority. This is a source
existence inventory, not a host, measurement, canonical or quantity handoff.
