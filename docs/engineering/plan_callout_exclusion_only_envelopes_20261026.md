# Exclusion-only callout envelopes

Source-neutral architecture brief; no drawing-derived observations or geometry.
Base: #3869 `5d2a4fe8badcf5e35eb00f9726644f89bec4f0c0`. This is a shadow-only
exclusivity repair within the temporary owner-authorized Claude takeover. The
separate W01 physical-assessment report remains at its review gate.

## Observed

Read `AGENTS.md`, the engineering playbook, accuracy-levers index, CI workflow,
and the existing callout-shadow module, fixture and tests.
`extract_native_page` in `pb_vector_geometry_v130.py` emits line/rectangle edges,
not cubic curves. `SourceVisibilityProducer` authenticates those segment
observations. The shadow adapter joins visible IDs to the producer's own byte-
verified primitives, while `_ring_for_word` searches only six-edge polygons.
`audit_plan_callout_to_glazing_strip_shadow` retains undecidable hex rings as
claimants but cannot currently oppose a candidate using a curved bubble or a
different closed polygon around a tag. `_word_claims` also excludes a word
centred over the strip band. `CalloutCorrespondence` is unsealed; its constructor
is not source or physical-opening authority.

The adapter also silently skips unavailable text receipts, failed visible
resolutions, and visible primitives that cannot be joined to source-native
geometry. An independent generated-source probe starts with a second hex-label
claimant and CONFLICT, then changes only the rival's ink resolutions to ABSTAINED
or removes its text receipt: the old head returns CANDIDATE in both cases. Source
authentication failure has therefore been mistaken for an empty rival inventory.

Two additional generated-source counterexamples: the adapter currently accepts
dashed path geometry as continuous closed ink; and `_axis_aligned` rounds stroke
widths to three decimals despite its exact-class contract, allowing distinct
width classes to jointly fabricate a strip that neither class supplies alone.
The strip builder also rounds source coordinates to two decimals before making
geometric decisions. A generated uniform-coordinate rescaling probe changes
three candidates into abstentions at small paper coordinates. Fixed cross-product
epsilons on ring containment are likewise dimensional and must follow source
coordinate equality rather than a fixed square-point tolerance.
Elevation panel enumeration has the same omission problem: in a generated
three-panel type against a two-panel plan strip, making one panel word untrusted
changes the old result from ABSTAINED to CANDIDATE. The trusted subset has been
mistaken for a complete panel inventory.

## Inference

A second opening label in a different envelope must not disappear because a
six-edge ring was not found. Geometry that lacks a visibility receipt cannot
become authenticated visible evidence. It can still indicate that the declared
hex-only claimant universe is insufficient for an exclusive association. That
is an abstention, not a positive bubble or opening classification.

## Proposed

Keep six-edge rings as the only target shape that can pass the current positive
correspondence gate. Add bounded general closed-polygon discovery for opposition,
using the same local word search and coordinate equality rules; preserve original
visible IDs. Distinguish missing polygon, ambiguous polygon and work exhaustion.
Retain uncertain rivals even when their words lie over the strip band.

For cubic native paths, re-read only the producer's own current SHA-verified
bytes. Group connected native drawing items into components, keep exact path/item
addresses, and expose locally enclosing curve envelopes only as unverified
exclusion receipts. They are never visible observation IDs. Absent/unknown paint,
clip or visibility proof cannot promote them. The receipt records why visibility
is unproven. Trusted non-opening labels do not acquire opening semantics; an
untrusted word's raw text is never used as identity. Use every eligible word,
independent of the output regex, for opposition.

The shadow result keeps the full exclusion inventory as well as per-row rivals.
The census emits those receipts, source scope and rival IDs for local review;
unverified native addresses have a separate field from visible observation IDs.
Track text and visible-ink inventory authentication independently. A missing
receipt, failed visible resolution or failed native join makes the page's
correspondence ABSTAIN with an explicit inventory reason. Known untrusted text
with an authenticated bbox remains an unknown-label claimant; known absent stroke
paint remains a non-stroke, not an integrity failure. Never cure missing evidence
by treating it as a smaller complete inventory.
Require independently joined native solid/opaque stroke paint for positive ring
and strip geometry. Keep uncertain dashed/partial-opacity envelopes as opposition
only, without changing the upstream visibility authority. Preserve exact source
stroke classes instead of silently rounding them together. These are shadow
gates, not a new paint/visibility or measurement authority.
Keep source coordinates unrounded inside the shadow and reserve display rounding
for the census. Use quantum-derived perpendicular equality for convexity and
strict containment, so coordinate rescaling does not change the proposition.
Retain untrusted elevation-word addresses inside each type frame and abstain on
panel inventory uncertainty. Such a type must not support another type's ratio
proof. Do not inspect the untrusted raw spelling to decide whether it was a
panel token.
Coordinate equality clustering must also have bounded diameter: adjacent near
coordinates must not chain into a representative farther than the declared
equality tolerance. This is a numeric-identity constraint, not a new scale fit.
The old local-turn convexity test also accepts a self-intersecting six-edge
star that winds twice around the word, allowing CANDIDATE. Require one winding
as well as strict local convexity; retain the same bounded path search.
All current grants remain False; no G17, host, schedule, issuer, signed-output,
evaluator, cap or snap change. No production importer or consumer is added.
Do not modify another agent's source/authority seam to fabricate curve support.

Expected failures: open/non-enclosing paths are not affirmative envelopes;
ambiguous or budget-exhausted local searches block affected claims; stale source
or malformed receipts fail closed; a valid rival blocks under broad/narrow report
patterns and insertion order. A plain word without an envelope is not promoted.

## Validation plan

Generated PDFs only for public fixtures: curved and polygonal rivals, trusted
and untrusted labels, over-band and both-side placement, nested/partial curves,
non-opening text, reversed/split/duplicate paths, work bounds, translation,
rotation, uniform scaling, byte/receipt corruption, deterministic replay and no
mutation. Real source checks remain private and cannot become public fixture
constants. Test cases are validation, not separate major accuracy milestones.

Exact-head execution receipts belong on the coordination hub. Public fixtures
are generated; private-source diagnostics stay local. The paint gates above do
not independently prove rendered overpaint/occlusion, curve visibility, physical
semantics or source-universe completeness; existing source-authority limits
remain. No new physical authority is created by a successful shadow result.

No benchmark value, expected quantity, project name, tag address, source SHA or
source-derived dimension is an algorithm input. No new scale, count, FIRM,
physical-opening, host, signed/customer or score claim follows from this repair.
