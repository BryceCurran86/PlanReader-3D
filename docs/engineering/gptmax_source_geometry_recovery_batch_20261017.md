# GPT MAX source geometry recovery batch — 2026-10-17

## Observed behavior and trace

Read `AGENTS.md`, `AI_ENGINEERING_PLAYBOOK.md` and the shared accuracy-lever
instructions. Trace: `SourceVisibilityProducer` → raster primitive/visible
receipts → `PhysicalWallCandidateProducer` W2/W4 →
`OpeningHostBindingProducer` → `OpeningHostFrameProducer` →
`compose_live_physical_opening_voids` → the existing publication, seal and
customer-verification contracts. The last three are exercised read-only.

The legacy nomination suppresses nearby, overlapping source spans. A whole W4
chain can fail the host-role prefilter even when an owned segment reaches the
opening. Supplemental positive bindings can omit plausible ordinary-source
competitors. Supplemental records do not reach frame consumers. Compact HHWW
labels already have an owned type/area interpretation, but no separate nominal
width/height review projection. New source capture changes snapshot ancestry;
reissuing the original receipts under that root is not immutable retention.
Wall materialization also iterates unrelated cached source revisions before
validating the requested page subset.

## Inference and proposed behavior

Retain nonidentical source nominations and nominate local chain segments, then
require the existing complete joint source/equivalence proof. Keep ambiguous
alternatives. Reingest native bytes into an independent producer to explore
source policy without mutating the original issuer. Export source-space and
nominal review facts using the existing physical evidence and canonical graph.
Do not infer whole-wall geometry, rough openings, metric placement, sill, scale,
door height, occurrence count or commercial authority.

Multi-page exploration preserves one original multi-page issuer and creates
independent per-page G17 hypotheses. It does not union page-local hypotheses
into a complete opening universe or a new signed aggregate.

## Authority boundaries and release limitations

Default topology/source policies remain off. Existing source SHA, render,
lineage, source ownership and physical-equivalence predicates still gate host
resolution. The five registered opening-local source families stay excluded
from ordinary page/F.07 W4. The 2.5pt snap, 4pt source-ink threshold and 20,000
primitive budget are unchanged.

Local frames are CANDIDATE results only and never enter `_results` used by the
positive whole-wall authority. Nominal canonical review objects have
`takeoff_eligible=False`, `deduction_authority=False`, and no wall placement,
sill or offset. OBJ assets are zero-depth X/Z faces at an unplaced origin.
Evidence packets and source-correspondence relationships cannot be imported
as authority, migrate signed rows or alias physical identities.

An unchanged original issuer during a fork proves within-run nonmutation.
It does not authenticate a historical archive. The report says this explicitly.
The alternate source root still changes old record lineage; its extra nominal
area is an audit candidate, not an approved appended commercial quantity.
No production customer writer, source PDF, frozen benchmark, scoring tolerance
or expected quantity is changed. Benchmark observations must not determine
nomination, source correspondence, wall identity or geometry thresholds.
