## Validation / privacy

Source-neutral tests cover genuine closed ring with door/fixture returns,
four physical sides, hatch and exact dual OCR, and negatives for ambiguous
overlaid rings, missing structural walls, missing tile hatch, missing /
conflicting OCR, invalid page, open or self-crossing polygons.

Private exact-SHA originals are required for the positive end-to-end and
tamper tests. On authentic owner-PC source, one original ground ENS tiled
floor ran through existing sealed/customer verifier; a separate original
first-floor ENS ring was proven as source candidate only. The existing
alfresco source/customer positive was independently checked.

Private receipts, source crop coordinates, PDF bytes, model weights and the
full native path inventory are NOT committed. Any score improvement requires
a separate authenticated source-role dispatch, immutable physical identity
map, unchanged evaluator run, and protected full-output retention.
