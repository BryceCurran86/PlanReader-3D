# One Original PlanReader application ? owner directive

Date: 12 November 2026 (Brisbane).

## One production architecture

Original PlanReader is the only live customer app/measurement pipeline.
The older source-closed benchmark is still frozen at 120 (27/24/63/6).
The experimental Next work is retained as a library of source-native
algorithms and tests, not merged wholesale as a new quantity engine.

Existing original app modules remain production outlets:

- Source bytes and revision: pb_source_visibility_authority
- Wall candidates / external footprint: pb_physical_wall_candidate_authority
- Wall/opening host frames: pb_live_wall_opening_authority_composition,
  pb_opening_host_frame_authority and pb_physical_opening_void_authority
- Actual rooms: pb_source_room_face_authority and
  pb_live_canonical_room_composition
- Floor/ceiling: existing cross-view finish and room-area authorities
- Full wall and door voids: pb_live_external_physical_net_wall_publication
- Commercial outputs: original QuantityEvidence and existing customer
  sealing and four-project evidence ledger

These are not replaced by planreader_next draft polygons or a second
ceiling area issuer. Source evidence must pass the same authority gates.

## Exact owner measuring rules

1. Trace external building footprint from original visible wall strokes,
   including dark-fill wall bars, not white background/mask bounding boxes.
2. Trace all internal structural and partition walls with real connected
   endpoints; unknown gaps must be explicit ABSTAIN.
3. Recognize door apertures, schedule/elevation frame heights and host walls.
   Close a confirmed doorway only for ROOM TOPOLOGY. This is not a
   physical wall or a measured full-height opening.
4. Identify spaces from closed true wall rings; each actual physical room
   must be separately accounted for. Multiple names inside an unpartitioned
   open area remain one connected area.
5. Measure internal finished wall faces, door thresholds, authentic ceiling
   material/height zones and other quantities through existing issuers.
   Do not tile underneath walls.
6. Above a physically confirmed door frame, retain the physical wall up to
   the source-authorized wall/ceiling head, unless a separate genuine void,
   transom or full-height opening is drawn and authenticated.

## Bounded production change in this branch

The original net-wall publisher already receives an independently
source-authenticated gross full-height whole-wall polygon and source-owned
opening void polygons. It subtracts the exact union, not a generic
door-sized full-height bay. A new final exact-geometry check enforces
that the part above a proved void head remains in the net wall polygon
unless another independently sourced opening void removes it.

Normal existing source-positive outputs remain byte- and quantity-
compatible. A bad subtraction algorithm that cuts the door bay
to ceiling height now produces a real publisher CONFLICT, not a
customer net-wall m2 row. Full-height voids and upper-level transoms
remain exceptions. This check does not guess a height or repair
an unverified room opening. All existing source/privacy/metric gates
remain mandatory.
