## Exact owner measuring rules

1. Trace external building footprint from original visible wall strokes,
   including dark-fill wall bars, not white background/mask bounding boxes.
2. Trace all internal structural and partition walls with real connected
   endpoints; unknown gaps must be explicit ABSTAIN.
3. Recognize door apertures, schedule/elevation frame heights and host walls.
   Close a confirmed doorway only for ROOM TOPOLOGY. This is not a
   physical wall or a measured full-height opening.
4. Identify spaces from closed true wall rings; each actual physical room
   must be separately accounted for. Multiple names inside an unpartitioned
   open area remain one connected area.
5. Measure internal finished wall faces, door thresholds, authentic ceiling
   material/height zones and other quantities through existing issuers.
   Do not tile underneath walls.
6. Above a physically confirmed door frame, retain the physical wall up to
   the source-authorized wall/ceiling head, unless a separate genuine void,
   transom or full-height opening is drawn and authenticated.

## Source-dark wall geometry wired to original canonical rooms

The ORIGINAL pb_layered_wall_doorway_room_ring_shadow now optionally
reads genuine source-native dark-gray, opaque, narrow PDF fill bars
even without an explicit wall-layer name. It preserves original native
path indices and uses the existing doorway-closure polygon builder.
No second commercial quantity issuer is introduced.

The option dark_painted_wall_source=False defaults OFF at the original
ring builder, SHA-pinned PDF reader and room-face scope. Canonical room
composition has layered_dark_painted_wall_source=False. To turn it on,
live caller must also enable layered_doorway_room_rings and
layered_finished_face_gate. The source room-face handoff independently
requires finished_face_gate. Physical wall and metric area authority
are NOT inferred from dark source paint alone.

Dark source bar detection requires almost monochromatic channels above
black threshold but no brighter than 0.25; opaque fill, no stroke,
native source rect/quad, narrow 1.2..14 PDF point bar with span >=8
PDF points and span / thickness >=4. Such source geometry is only a
candidate; the thresholds are NOT globally source-authenticated wall
dimensions. White background fills, translucent decoration, short
symbols, broad cabinets and strokes with competing paint are excluded.

## Generic segmented-door source witnesses and bounded topology chords

Owner explicitly rejected programming D07/D08/D13 individually. The
ORIGINAL room source pipeline now has ONE reusable source-native detector:
`pb_source_segmented_door_swing_shadow.collect_source_black_segmented_door_swings`
recognises a connected black quarter-swing drawn as consecutive original
PDF line paths, with a UNIQUE separate radial leaf. It yields original
path indices, hinge, OPEN tip and CLOSED leaf position. No door IDs or
project-specific coordinates are embedded in that code.

`propose_source_owned_doorway_chords` consumes those normalized source
witnesses, original black wall-end and jamb strokes on BOTH sides and
a bounded parent wall-band interruption to build ONLY the local actual
door-width topology chord. The source proves the real closed endpoints;
it is NOT the full large PDF gap and does NOT create a physical wall
through a doorway. An existing source threshold line may be included
but is **not required**, because architects differ in door symbols.
The common gate works with horizontal and vertical swing openings and
variable source door widths. A drawing missing a supporting wall end or
with multiple competing band owners abstains instead of guessing.

**Source replay, original Maryborough p7/A110**: 12 segmented swing-plus-leaf
witnesses, **2** corroborated bounded topology-doorway closures, including
PWD D13, other ten do not meet current source wall-end proof. 116 traced
black wall strips; six prior provisional topology rings; no source FIRM
room area, no customer-facing quantity and NO frozen120 score credit.
These are source-topology observations, not 2 independently authenticated
physical door/host/height quantities. Wall above the authenticated frame
to actual ceiling height remains the separate original net-wall rule.

The segmented black-line detector is one **input adapter** for a shared
physical doorway source gate. Other CAD representations (native bezier
swing, slider, stacker, fixed opening, door schedule/host) require their
own source evidence adapters, NOT a bespoke hardcoded per-door fix.
A single geometry/host/finished-face authority must decide promotion.
