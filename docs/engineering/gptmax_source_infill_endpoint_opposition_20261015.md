# Original source infill at a W3 endpoint

## Observed

Read the agent contract, engineering playbook, W2-W4 specification and
observability architecture. Traced `build_g17_source_infill_opposition_shadow`,
`_infill_interval`, `_infill_edge_opening_ids`, W2 source-fragment lineage,

`_resolve_raster_source_band_host_from_records`.

The source-owned infill observer currently blocks continuity only for an edge
entirely covered by one original opening's authenticated infill intervals. A
real original edge has a short unclassified portion at one end, while its
OTHER endpoint is inside its own infill interval. Whole-edge abstention is
correct; it does not prove the other endpoint has no local opposing evidence.
Default W2 nodes may average differently sampled source endpoints; a W3
position is not a replacement for the actual original endpoint or interval.

## Inference

Endpoint-local opposition can be retained separately without relabeling the
whole edge. An infill-covered endpoint may oppose structural continuation at
that endpoint, while a remote/ambiguous endpoint cannot. Partial overlap in
the middle of an edge cannot select either endpoint. One opening cannot lend
its intervals to another opening to bridge a coverage hole.

## Proposed shadow and review

Keep the current whole-edge experiment unchanged. Add a separately opt-in
candidate partition whose CONTINUES_AS barrier requires actual source ancestry,
a positive collinear interval through one actual edge endpoint, and an
unambiguous endpoint incidence at the real W3 junction under the unchanged W2
snap policy. Retain all original W2 geometry and W3 relationships, actual
endpoint, interval, source/opening IDs, and residual unknown geometry. Retain
whole-edge, endpoint-only and ambiguous/no-op outcomes separately. Reassemble
only the additional shadow W4 partition, never default W4 or host authority.
