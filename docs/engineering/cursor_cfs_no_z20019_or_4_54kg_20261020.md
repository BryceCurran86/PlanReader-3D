# Architecture: CFS purlins must not invent Z20019 sections or 4.54 kg/m mass

## Observed repository behavior

`CFSMemberSpec` defaults to `Z20019` at `4.54` kg/m. `parse_callout` initializes and falls back to those figures. `get_linear_mass` returns `4.54` when the designation is unknown.

## Inference

A typical Z20019 purlin is not owned evidence.

## Proposed change

Omitted designation stays empty and omitted mass stays `0.0`, including parse fallbacks and the unknown-designation mass table miss.

## Benchmark observations that must not influence implementation

Expected purlin tonnes and project names are not inputs.
