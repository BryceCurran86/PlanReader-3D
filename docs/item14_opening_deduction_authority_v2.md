# Item 14 — Opening Deduction Authority V2

Item 14 authorizes one exact opening deduction only after four independent sealed propositions replay on the same immutable source lineage:

1. physical opening void;
2. opening host binding;
3. complete opening universe for the decision scope; and
4. target applicability, itself joined from source-proven target scope and governing rule.

The public selector is address-only. A physical void never implies deduction permission. `target_scope_id` is an address and never truth. Unknown, ambiguous, conflicting, stale, or mismatched target/rule evidence fails closed without numeric zero or downstream commercial authority.

The applicability source parser recognizes only explicit project-source `ODTARGET(...)` and `ODRULE(...)` declarations that survive the existing trusted native-PDF text-integrity boundary. These declarations are evidence; they are not defaults. No AS 4041 shortcut or implicit measurement standard is used.

The final deduction record retains the exact physical void, host binding, opening-universe, and applicability record IDs. It does not mint net wall area, commercial quantity, FIRM status, or JobHub authority.
