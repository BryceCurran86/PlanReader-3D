## Generic source-role architecture: AGENTS.md review gate

**Problem:** a coarse `sheet_view_type=ELEVATION` on p10 Lot16 could discard a useful local cabinet measurement; a coarse `INTERNAL_ELEVATIONS` on Maryborough A502 could discard the embedded **PWD PLAN** dimensional floor witness; a coarse RCP page type could confuse the *interior* A120 RCP with *forecourt canopy* A251/A253 RCP. A word `2127` can be a meaningful opening code without independently supplying width and height.

**Review proposal (NOT implementation):**

1. **Sheet record:** original document SHA + exact revision + PDF page index + drawing number + title source observation IDs + canonical producer snapshot.
2. **Individual view records:** distinct bounded plan/elevation/section/detail/schedule subviews, each carrying original native title/scale source ID, page bbox, owner/source observation lineage, kind and physical object family admissibility; mixed views may coexist on the same page.
3. **Dimension target binding:** original figured dimension native stroke/text record must prove endpoint segment geometry, orientation/unit, view membership and **semantic target** (room floor perimeter, cabinet frontage, height datum, glazed frame width, etc.). A cabinet elevation's `1050` never mints a room floor width, and 2100 FSL–JL never silently becomes an arbitrary opening's height.
4. **Cross-view physical identity:** same-root PDF page/revision is necessary but not sufficient. Original evidence must prove the p3 `2127` plan opening corresponds uniquely to p5 Elevation 4 glazing, and p3 LINEN matches p10 laundry cupboard, with conflicting candidates retained and source snapshots immutable.
5. **Source-gated quantities:** consume existing room/opening/ceiling producers only when all relevant original roles, dimensions, canonical identities and signed provenance pass. Never promote sheet title, proximity, label similarity, viewport presence or OCR-only text as area evidence.

**Test matrix before any production changes:** original positives p3+p5 STACKER, p3+p10 LINEN, A110+A502 PWD, A110+A140 FT3 and A110+A120 ceiling; negatives 2127 outside Elevation 4, 2100 attributed to wrong opening, same-text different source observation, A251/A253 canopy RCP as building interior, Mary A600 schedule cross-applied to Lot16, rotated/cropped/reordered/synthetic source, no height or width, stale SHA/graph snapshot, mixed subview overlaps, input permutation and replay invariance. Preserve all **eight** accepted Lot16 opening-area source/customer values under original measured-label contracts, prior three Maryborough signed room areas, 20k raster cap, W2 2.5pt snap and frozen evaluator.
