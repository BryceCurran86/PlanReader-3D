# Photographic architectural presentation assets
All assets are CC0-1.0 from Poly Haven, obtained only at build time using their documented files API. The build fails if a required file is missing or does not match provider size and MD5. Subsequent local builds reuse files checked against their recorded SHA-256. Runtime requests are same-origin and are not forwarded to Poly Haven. Generated assets are copied into dist by Vite.
- Wood Floor (Dimitrios Savva): https://polyhaven.com/a/wood_floor — 1k diffuse, GL normal and roughness; 1.7 m repeat, neutralized diffuse for editable colourways.
- White Plaster 02 (Rob Tuytel): https://polyhaven.com/a/white_plaster_02 — 1k GL normal and roughness, 1 m repeat.
- Leafy Grass (Charlotte Baglioni): https://polyhaven.com/a/leafy_grass — 1k diffuse, 2 m repeat.
- Suburban Field 02: https://polyhaven.com/a/suburban_field_02 — 2k HDR sky and reflection environment.
License: https://polyhaven.com/license. These are presentation assets only, not quantity evidence, and do not represent the actual source project surroundings.
The actual provider downloads, browser decoding and visual performance must be verified on the release build. Procedural materials remain for unconverted material families.
